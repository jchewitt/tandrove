# PERF-01 validated-input reuse review

Independent reviewer: `/root/canonical_review`, October 26, 2026. The primary agent implemented the optimization, collected measurements and updated documentation; `/root/canonical_tests` independently authored eight public regressions. No commit preceded independent review.

Scope: a private weak map recognizes only array-free, deeply frozen, null-prototype object subgraphs allocated by `snapshotInput`, reuses those values and lazily caches canonical strings. A scalar sentinel avoids per-entry metadata allocations. Serialization-only copies do not register provenance. Caller-owned inputs, shallow-frozen containers, proxies and mixed untrusted descendants retain validation. Arrays and their containing objects still execute copying/iteration/native serialization; safe descendants can be reused. Snapshot copy identity is unspecified. No new public trust API, projection shortcut, adapter dependency or state identity is introduced. A core patch Changeset joins the batched release.

The reviewer approved the final implementation and tests without actionable runtime findings. They reran **24,025 old-versus-candidate comparisons**, derived from 12,000 generated nested inputs plus captured/mixed forms and 23 edge factories. Checks included normalized values, canonical strings, validation failures, deep freezing, mutable inputs, proxies and value-based array hooks. All comparisons passed, as did an independent run of the **eight new regressions**. This is evidence for the tested histories, not a proof of all possible JavaScript hooks; arbitrary identity-sensitive hooks cannot assume each descendant is copied anew. Review findings about overbroad hook wording and unproven memory attribution were corrected and re-reviewed.

The primary agent passed `pnpm check`: formatting, package builds, generated schema checks, strict source/type checks, **437 tests** and isolated real-tarball ESM/TypeScript/Angular APF/AOT consumers. `pnpm test:browser` passed **25 Chromium scenarios**. Hosted CI and merge evidence belong to the feature PR. Timing thresholds are not part of the correctness suite.
